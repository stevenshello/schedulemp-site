Connection help

Quick answers for installing ScheduleMP, finding servers, and resolving version mismatches.

Server does not appear

Confirm its signed heartbeat is accepted and that gameplay, status-query, and Steam query ports are publicly reachable.

Connection refused

Check that Schedule I, S1DS, and required server mods all use matching versions.

Report a server

A verified reporting and moderation workflow will be enabled before third-party public listings open.

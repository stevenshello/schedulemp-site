Build on ScheduleMP

Connection, listing, hosting, and integration guidance for players and server owners.

For players

Install the client, browse servers, save favorites, and connect directly.

For server owners

Configure S1DS, publish ports, register a signed heartbeat, and advertise up to the current S1DS limit of 64 slots.

Listing protocol

Servers sign heartbeats with HMAC-SHA256. Offline listings expire automatically.

POST /api/v1/servers/heartbeat

Server API

Query live server metadata and integrate custom server/client modules through S1DS.

GET /api/v1/servers

SERVER OWNERS

List or import your server

If an S1DS server does not appear automatically, register it with ScheduleMP's signed heartbeat agent.

  1. Set a public hostname or IPv4 address and keep S1DS running with authProvider = 'SteamGameServer'.
  2. Open and router-forward 38465/UDP, 38465/TCP, and 27016/UDP.
  3. Create a server ID and request a unique listing secret from the ScheduleMP operator. Never share that secret with players.
  4. Copy the server registration template, enter the master-list URL, server address, region, map, mode, build, and capacity.
  5. Run the heartbeat agent beside S1DS. An accepted heartbeat appears in the browser immediately and refreshes every 30–60 seconds.

Still missing?

Confirm the server and heartbeat clocks are correct, the ID matches the issued secret, the advertised player count does not exceed capacity, and the public ports reach the server PC. Listings are removed about 90 seconds after their last accepted heartbeat, so keep the agent running. Steam listing alone does not authorize a ScheduleMP entry; signed registration prevents impersonation and fake servers.

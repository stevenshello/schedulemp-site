WINDOWS CLIENT

Download ScheduleMP

Install all three components below before connecting to a ScheduleMP server.

STEP 1

ScheduleMP launcher

Installs the Windows server browser and its Connect buttons.

DOWNLOAD SCHEDULEMP.EXE

Version 0.2.4 · Windows 10 and 11. Windows may require More info → Run anyway.

STEP 2

MelonLoader installer

Download MelonLoader.Installer.exe, select Schedule I, then install version 0.7.2 x64. Do not use 0.7.1.

DOWNLOAD MELONLOADER

STEP 3

S1DS IL2CPP client

Download Il2cpp_Client.zip from the latest release. Extract it into the Schedule I folder and merge its Mods folder.

DOWNLOAD IL2CPP CLIENT

Install order

  1. Install Schedule I through Steam and close the game.
  2. Run MelonLoader.Installer.exe and install MelonLoader 0.7.2 x64 into Schedule I.exe.
  3. Extract Il2cpp_Client.zip into the Schedule I installation folder.
  4. Install and open ScheduleMP, select the server, and press Connect.
